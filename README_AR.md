# إدارة التقسيط — إبراهيم

تطبيق Streamlit مستقل بنفس أسلوب Personal Wealth: واجهة عربية داكنة، وملف Excel هو مصدر البيانات. كل إضافة وتعديل وصرف وسداد يكتب في الإكسل عند نجاح الحفظ.

## التشغيل على الكمبيوتر

1. فك ضغط الحزمة كاملة في مجلد واحد.
2. ثبت النسخة القياسية من Python 3.12 أو 3.13 أو 3.14 (64-bit)، وفعّل خيار إضافة Python إلى PATH أثناء التثبيت.
3. على Windows افتح `Start_Windows.bat`. وعلى Mac/Linux شغّل `sh start.sh` من داخل المجلد.
4. يفتح التطبيق في المتصفح. يبدأ تلقائيًا باستخدام `Installment_System.xlsx` المرفق.

أو شغّل يدويًا:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

هذا الوضع يكتب في الملف الموجود على نفس الكمبيوتر. يوجد زر لتحديث قراءة الملف وزر لتنزيل أحدث نسخة، وتنشأ نسخة احتياطية قبل كل تغيير. لا تفتح ملف الإكسل للتحرير أثناء حفظ عملية من التطبيق.

## العمل من الجوال والكمبيوتر — OneDrive

1. ارفع ملف `Installment_System.xlsx` في مجلد `Installment System` في جذر OneDrive. انتبه: ليس داخل Documents إلا إذا غيّرت `onedrive_folder` إلى `Documents/Installment System`.
2. ارفع ملفات البرنامج إلى مستودع خاص، وشغله في تطبيق Streamlit جديد. ملف التشغيل هو `app.py`. لا تنشر البرنامج في Sites؛ هذا برنامج Python يحتاج استضافة Streamlit أو خادم Python.
3. افتح إعدادات التطبيق → Secrets، والصق محتوى `secrets.example.toml` بعد استبدال القيم التجريبية. في الكمبيوتر يمكن حفظها في `.streamlit/secrets.toml`.
4. تستطيع استخدام بيانات تسجيل تطبيق Microsoft التي تستخدمها مع Personal Wealth. أضف عنوان تطبيق التقسيط الجديد إلى **Web Redirect URIs** في تسجيل تطبيق Microsoft، وضع نفس العنوان حرفيًا في `redirect_uri`. لا تحذف عنوان تطبيق الثروة.
5. الحساب الشخصي يستخدم `authority = "consumers"`. لحساب مؤسسة استخدم `common` أو tenant المؤسسة الذي تسمح به إعدادات تطبيقك.
6. استخدم الصلاحيات المفوضة `User.Read` و`Files.ReadWrite` كما في تطبيق الثروة. سجّل الدخول إلى Microsoft من تطبيق التقسيط.
7. عند نجاح الدخول سيظهر «الحفظ: OneDrive». كل عملية ناجحة تحفظ مباشرة في ملف التقسيط هناك، دون رفع CSV أو Excel بعد كل عملية.

لا توجد كلمات مرور أو رموز وصول حقيقية في هذه الحزمة. استخدم القيم الموجودة لديك في إعدادات التطبيق؛ لا تضعها في GitHub أو داخل الإكسل. لا تنشر وضع الملف المحلي للعامة لأنه يستخدم ملفًا مشتركًا على الخادم؛ استخدم OneDrive مع تسجيل دخول Microsoft عند الاستضافة. الربط الحقيقي بحسابك لا يمكن اختباره دون إعداده وتسجيل الدخول.

### مثال إعدادات

```toml
[storage]
mode = "onedrive"

[microsoft]
client_id = "بياناتك الموجودة"
client_secret = "بياناتك الموجودة"
tenant_id = "consumers"
authority = "consumers"
redirect_uri = "https://عنوان-تطبيق-التقسيط.streamlit.app/"
onedrive_folder = "Installment System"
```

لا تغير اسم ملف التقسيط إلى اسم ملف الثروة. البرنامج يرفض ذلك لحماية ملف Personal Wealth.

## أول عملية

1. العملاء → إضافة عميل. أضف اسمه وجواله وباقي المعلومات المطلوبة.
2. العقود → إنشاء عقد. اختر العميل وأدخل أصل التمويل، إجمالي السداد الفعلي، المدة وأول استحقاق والرسوم.
3. العقد مسودة ولا يؤثر على السيولة. افتحه واختر صرف التمويل لتسجيل خروج رأس المال.
4. عند السداد افتح العقد → سداد قسط. المبلغ يمكن أن يكون جزء قسط أو أكثر من قسط.
5. للسداد المبكر أدخل النقد المدفوع والخصم المتفق عليه؛ يجب أن يساوي مجموعهما كامل المتبقي.
6. أي خطأ مالي يصحح من الحركات المالية. التصحيح يحتفظ بالحركة القديمة كملغاة، ويضيف بديلًا ويعيد الحساب.

## رصيد البداية والمطابقة مع نوشن

- نقلت حركة رأس المال الظاهرة: **100,000 ريال بتاريخ 1 يوليو 2026**. لا توجد عملاء أو عقود وهمية في الملف المرفق.
- إذا كان رصيد نوشن مجرد مثال، عدّل حركة رأس المال من الحركات المالية قبل بدء الاستخدام، أو ألغها ثم أضف رأس المال الفعلي.
- تم فحص أعمدة قواعد العملاء والعقود والحركات المالية المنشورة في الرابط المرجعي، ومطابقة الأقسام والحقول الرئيسية.
- رابط العرض العام لا يكشف معادلات نوشن الداخلية أو منطق الأزرار. لهذا لا ندعي نسخ تلك المعادلات حرفيًا. التصنيف A–D يدوي، وعدد مرات التأخير يحسب من السجل.
- الافتراض الأولي للعقد الجديد 16 شهرًا وربح إجمالي 60%، ويمكن تغييره من الإعدادات. **إجمالي السداد الذي تدخله لكل عقد هو المعتمد**؛ لا تغير الافتراضات العقود القديمة.

## قواعد الحساب

- المبالغ تحسب بالهللة الصحيحة، وتقسم الأقساط مع إضافة فرق التقريب للقسط الأخير. يحتفظ التاريخ بيوم الاستحقاق الأصلي: 31 يناير → 28 فبراير → 31 مارس.
- الصرف يخصم أصل التمويل مرة واحدة. تحصيل الرسوم مستقل عن الأقساط، ويضاف للسيولة عند تسجيله فقط.
- السداد يوزع على أقدم قسط غير مسدد. الخصم يغلق الجزء المتبقي ولا يضاف للسيولة.
- السيولة = رأس المال والإضافات + السداد + الرسوم − التمويل المصروف − السحوبات − المصروفات.
- التحصيل يشمل أصل التمويل والربح. الربح التعاقدي المتوقع ليس ربحًا محققًا، ولا توجد شاشة توحي بأن كامل التحصيل ربح.
- المتبقي من أصل التمويل = الأصل × المتبقي من إجمالي السداد ÷ إجمالي السداد. هذا تقدير بالتناسب ولا يحدد قيمة السداد المبكر قانونيًا أو تعاقديًا.
- الحد الائتماني صفر يعني عدم وضع حد. عند الصرف يقارن البرنامج التمويل القائم تقديريًا + الصرف الجديد بالحد اليدوي المحدد. العميل الموقوف لا يصرف له تمويل جديد.
- تاريخ القسط السابق لليوم دون اكتمال السداد يعد متأخرًا. السداد في يوم الاستحقاق لا يعد متأخرًا. يحتفظ السجل بعدد أيام تأخير الأقساط المسددة بعد موعدها.
- الإلغاء والاستعادة يعيدان بناء توزيع التحصيل. لا يمكن إلغاء صرف عقد مع بقاء تحصيلاته، أو سحب رأس مال بحيث تصبح السيولة التاريخية سالبة.
- مرجع التحويل المكرر يرفض. ولكل حفظ رقم طلب يمنع تكرار الحركة عند إعادة إرسال الطلب نفسه.
- يتحقق الحفظ من نسخة الملف؛ تعارض النسخ يوقف الحفظ بدل الكتابة فوق النسخة الأحدث. عند انقطاع التأكيد لا تعاود تسجيل العملية مباشرة: حدّث الملف وراجع رقم الطلب في سجل التغييرات.

## أوراق الإكسل

`ملخص المحفظة`، `العملاء`، `العقود`، `الأقساط`، `الحركات المالية`، `توزيع التحصيل`، `متابعة العملاء`، `الإعدادات`، `سجل التغييرات`.

المدخلات والسجلات الأصلية هي المرجع. التطبيق يعيد الحساب منها، ولا يعتمد على ذاكرة نتائج الصيغ المخزنة في Excel. الصيغ تتحدث عند فتح الملف في Excel. جداول توزيع التحصيل وحقول الأرصدة ناتجة من التطبيق، فلا تدخل فيها حركات يدويًا. لتغيير البيانات استخدم التطبيق.

## النسخ والاستعادة

الحفظ المحلي يحتفظ بآخر 30 نسخة في `backups`. يمكن تنزيل نسخة واختيارها في «استعادة نسخة Excel». OneDrive يحتفظ أيضًا بتاريخ الإصدارات، والبرنامج يحتفظ بنسخة استرداد مؤقتة على الخادم قبل الحفظ. النسخة المؤقتة ليست بديلًا عن تاريخ OneDrive، وقد تزول عند إعادة تشغيل الخادم.

## الاختبار

أرفقت الاختبارات لتشغيلها عند تطوير البرنامج:

```bash
python -m pip install pytest
python -m pytest -q test_core.py test_app.py
```

تشمل الصرف والتحصيل والهللات، التواريخ، التسوية، الإلغاء والاستعادة، التكرار، الحدود، سلامة الحفظ، فحص صفحات الواجهة واختبار سداد عبر الواجهة ينعكس على الإكسل. اختبارات OneDrive تحاكي الردود ولا تثبت اتصالًا فعليًا بحسابك.
